# BetterBulakan — LGU outreach brief

**Audience:** Municipal ITO / MPDO / Mayor’s Office / PIO  
**Contact (portal):** GitHub [@kuyacarlo](https://github.com/kuyacarlo) · repo https://github.com/betterbulakan/betterbulakan

## What this is

BetterBulakan is a volunteer civic-tech portal. It helps residents find public information about the Municipality of Bulakan.

It does **not** replace eLGU. eLGU remains the place for permits, clearances, and transactions.

| Layer | System |
|-------|--------|
| Do a transaction | eLGU |
| Find services, officials, ordinances, budgets, procurement | BetterBulakan |

## What we already use (public)

- eLGU news / ordinances / Citizen’s Charter links
- Provincial page (officials, barangays, contacts)
- National PhilGEPS and DPWH search (BetterGov Meilisearch)

## What we ask for

1. Batch PDFs or files for ordinances, resolutions, and executive orders
2. Official PhilGEPS organization name for the municipality
3. Full Disclosure Policy / budget / bid-result packs for the current FY
4. OK to deep-link the Citizen’s Charter and municipal logo with attribution
5. One named contact for quarterly data refresh

## What we offer

- Searchable citizen UX for data the LGU already publishes
- PhilGEPS and DPWH views without new LGU software
- Optional short session for ITO on keeping sources current
- Independent maintenance — no hosting cost pushed to the LGU
